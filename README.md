## 📖 项目简介（Project Overview）

Sweet Venom（甘之如饴） 是一款基于 Twine 2 开发的互动叙事游戏。

以 1980 年代香港为故事背景。玩家将扮演一名年轻记者，在调查一宗尘封多年的案件过程中，逐步揭开父亲蒙冤背后的真相。随着调查不断深入，玩家需要在不同人物之间建立信任、收集线索，并通过关键选择影响剧情的发展方向。不同的决定将塑造人物关系，并最终导向截然不同的故事结局。项目希望通过非线性叙事与互动选择，让玩家不仅作为故事的见证者，更成为推动剧情发展的参与者。

## 💡 设计思考（Design Thinking）

本项目希望突破传统视觉小说中”阅读文本”的体验，而是让玩家通过一次次选择主动参与故事的发展。
因此，在剧情设计过程中，我们更加关注：
* 如何让每一次选择都具有叙事意义；
* 如何通过角色互动建立情感连接；
* 如何利用变量系统记录玩家行为，使不同选择在后续剧情中产生反馈；
* 如何让玩家感受到调查真相的过程，而非单纯观看故事。
相比单一路线，本项目更强调玩家在互动过程中的参与感，希望让不同玩家获得各具特色的叙事体验。

---

## 🔄 设计迭代（Design Iteration）

1. 剧情节奏优化：

项目初期剧情以大量连续文本推进，但试玩后发现阅读节奏较慢。因此对剧情进行了重新拆分，通过增加角色互动、环境描写以及玩家选择，使整体节奏更加紧凑，也增强了玩家的参与感。


2. 分支结构调整：

为了避免玩家产生”无意义选择”的体验，重新梳理了多个剧情节点，使重要选择能够真正影响角色关系、事件发展以及最终结局，增强选择的反馈感。


3. 交互体验优化：

利用 JavaScript 对变量系统进行了完善，实现了角色状态记录、剧情条件判断以及存档功能，使玩家能够获得更加流畅且具有连续性的互动体验。
